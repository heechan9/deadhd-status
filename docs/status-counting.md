# 진행 그래프 집계 기준

이번 최종제출 필수만 분자·분모에 포함한다. 분자는 필수 카드 중 state=done, 분모는 모든 필수 카드다. 완료된 확장도 제외한다. 자동 Git/CI와 과거 검증은 참고 정보로 제외한다. 현재 논문 주장에 영향을 주는 오류·검증은 미완료 그대로 필수 유지한다. 추가 실선·확장 실험 자체가 제출 범위 밖이어도 그 한계·제외·미해결 상태의 최종 원고 검토는 필수다. 분류 변경은 근거와 사용자 승인 범위에 맞춰 검토해야 하며 완료율을 높이려고 바꾸지 않는다.

본 연구는 병커의 규칙/DQN 합성 비교·민감도와 인용 공공자료, 적대적AI의 Clean/FGSM/고정 필터 비교다. 모델 교체 후보·추가 계획기·구매 최적화·운영/실선 실험, CNN 적대적 학습·Square/SurFree·BIM/PGD/JSMA 및 추가 통합은 제출 이후 확장으로 보존한다. 웹의 제출용 시연 QA는 필수, 추가 실기기 검증은 후속이다.

## 자동 조회와 집계

카드에 연결된 PR 의 열림·Draft·병합·CI 조회 결과는 카드 본문과 증거 링크의 텍스트로만 표시한다. 카드의 `state`·`countScope` 는 자동으로 바뀌지 않으며, 이 문서의 분류와 분자·분모는 수동 검토로만 바뀐다. 조회 실패·오래된 기록·`curatedAt` 경과를 알리는 자동 항목(`pr-live-failed`, `curated-stale`)은 `countScope` 가 없어 필수 집계에 들어가지 않는다.
